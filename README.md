AI를 활용한 로또 및 연금복권 번호 생성 서비스
 
<details>
<summary>더보기</summary>
<br>
2024년 AI가 주목받던 시기에 직접 만들어보며 감을 익히고 싶었고, 평소 관심 있던 로또 및 연금복권을 주제로 정했습니다.
<br>
두 상품 모두 독립시행이라 이전 회차 결과가 다음 회차에 영향을 주지 않는다는 점을 고려해, 예측의 정확성보다는 AI 활용 경험과 재미에 초점을 맞췄습니다.
<br> 
<br>
기획부터 프론트엔드, 백엔드, 배포, 운영까지 전 과정을 혼자 진행했습니다.
<br>
  
주 단위(회차 마감 후)로 당첨 번호를 자동 수집해 DB에 적재하고, OpenAI 응답을 `generateObject` + `Zod` 스키마로 검증해 할루시네이션과 형식 오류를 방지하는 구조를 만들었습니다.
<br>
별도 마케팅 없이도 소수의 사용자가 꾸준히 쓰고 있고, 지금도 계속 수정하며 운영하고 있습니다.

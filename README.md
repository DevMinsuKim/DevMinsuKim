## Side Project

**[clover-pick](https://github.com/DevMinsuKim/clover-pick)** <sub>개인 프로젝트 / 2024년부터 운영 중</sub>

AI를 활용한 로또 및 연금복권 번호 생성 서비스

<details>
<summary>더보기</summary>
<br>

AI API를 직접 서비스에 적용해보기 위해 시작한 개인 프로젝트입니다.
<br>
로또와 연금복권은 이전 회차의 결과가 다음 회차에 영향을 주지 않는 독립시행이라는 점을 고려해 예측 정확도보다는 AI 활용 경험과 사용자에게 제공하는 재미에 초점을 맞췄습니다.

<br>

기획부터 프론트엔드, 백엔드, 배포, 운영까지 전 과정을 직접 진행하고 있습니다.

주 단위로 당첨 번호를 자동 수집해 DB에 적재하고, OpenAI 응답은 `generateObject`와 `Zod` 스키마를 통해 검증해 형식이 보장된 데이터만 애플리케이션에서 사용하도록 구성했습니다.

별도 마케팅 없이도 사용자가 지속적으로 유입되고 있으며, 실제 운영 과정에서 발견한 문제를 수정하며 서비스를 개선하고 있습니다.

<br>

`Next.js` `TypeScript` `PostgreSQL` `Prisma` `OpenAI API` `Zod` `Sentry`
